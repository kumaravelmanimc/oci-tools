Upload Files to OCI Object Storage

Enter the temporary upload link provided by your administrator. Files transfer directly from this browser to Oracle Cloud Object Storage.

The URL must end in /o/. The link is not stored by this page.
Choose one or more files to upload.
Large-file limitation: This version uses single-request uploads. OCI Object Storage single PUT uploads have a 50 GiB limit per object. Files larger than that require a multipart-capable uploader. An interrupted upload cannot be resumed here. Keep this tab open while uploading.

Customer instructions

  • Upload only files authorized by the receiving team.
  • All file extensions are accepted by this page; PAR permissions govern actual OCI access.
  • Keep original filenames. Objects with matching names may overwrite existing objects.
  • Share filenames and sizes with your support contact.
  • Never forward the PAR link to unauthorized people. OCI PAR permissions, not this page, determine access.
