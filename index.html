OCI Tools
Oracle Cloud transfer and database utilities

Available tools

Browser-based utilities for transferring files with temporary OCI PAR URLs and generating reviewable OCI database runbooks.

Oracle Dump Upload →

Upload Oracle Data Pump .dmp files, including multiple export pieces.

File Uploads →

Upload general files to an OCI Object Storage bucket.

PAR Download →

Browse and download objects using a bucket-level read PAR URL.

Script Generator →

Generate Bastion, DBMS_CLOUD, Data Pump, Object Storage, and database-user commands.

PAR URLs and entered values remain in the active browser tab. Review every generated command before running it. Do not publish credentials or PAR URLs in the repository.
